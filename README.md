# Hindenburg
A basic, now defunct, exploit made in C# for the Airship Platform.
## Purpose
This exploit served for me and my friends to better understand the Luau C API alongside just making a utility software for Bedwars 2.
However now that the platform has permanently shutdown, I've decided to release this to the public.
The source code is mostly based off of RbxStu V2/V3, which served as a good (copy pasting) and learning resource to help better structure the project in general.
